# Time Tracker data: rules for agents

This is a data repository of repository-db, not code. Change records through
the Time Tracker App or its HTTP API, which check who may change what and the
rules across records; never commit, push, rebase or merge here by hand. A
publish is a Publication into the Organization's data and happens only on the
person's instruction.

- One record per file, `data/<collection>/<id>.yaml`, in the engine's
  envelope (`schemaVersion`, `id`, `record`) and its stable YAML.
- `schemas/` is generated by the Module; a change of the record shape arrives
  as a pull request together with a release of the Module.
- `bun scripts/validate.ts` must pass. Overlapping entries of one person are
  reported by the Module's `bun run validate:db`.
- Time entries are personal data. Never copy them into another repository,
  an issue or a chat.
